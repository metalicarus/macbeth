# Como contribuir

Obrigado pelo interesse no Macbeth.

## Termo de cessão de direitos (CLA)

O código deste repositório é distribuído sob a licença AGPL v3. Para aceitar uma contribuição, pedimos que a pessoa assine um termo de cessão de direitos (CLA, *Contributor License Agreement*). O termo é aceito no próprio pull request, na primeira contribuição.

Sem o termo assinado, o pull request não pode ser incorporado.

## Commits

- Mensagens em português, no imperativo: "Adiciona cadastro de personagens".
- Commits pequenos, cada um com uma mudança só.
